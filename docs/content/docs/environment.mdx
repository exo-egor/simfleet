---
title: Environment variables
description: Runtime settings for the server, CLI, and tools.
---

| Variable | Default | Purpose |
| --- | --- | --- |
| `SIM_FLEET_UI_PORT` | `8790` | Dashboard and API port. The server always binds to `127.0.0.1`. |
| `SIM_FLEET_URL` | `http://127.0.0.1:8790` | Where the CLI, menu-bar icon, and dashboard dev server find the API |
| `SIM_FLEET_PROJECT_ROOT` | nearest `.sim-fleet` | Project to serve |
| `SIM_FLEET_SIMSLIM_PROFILE` | project config | Host-specific SimSlim profile path; overrides `simslimProfile` |
| `SIM_FLEET_TRAY` | `1` | `0` disables the menu-bar icon |
| `SIM_FLEET_AUTO_SLIM` | `1` | `0` disables auto-slim |
| `SIM_FLEET_ANDROID_RAM_MB` | `2048` | Guest RAM for emulator boots, unless `android.avdslimArgs` sets `--ram=` |
| `SIM_FLEET_METRO_WORKERS` | `1` | Metro `--max-workers` per lane |
| `SIM_FLEET_CONTROL_PORT` | `8421` | Port for the Baguette simulator transport |
| `ANDROID_HOME` | `~/Library/Android/sdk` | Android SDK location |
| `AVDSLIM_BIN` | `PATH` | avdslim binary |
| `SCRCPY_SERVER_PATH` | Homebrew's `scrcpy-server` | scrcpy device server used for live Android video |
| `SCRCPY_SERVER_VERSION` | from `scrcpy --version` | Must match the device server's version |

## Agent identity

| Variable | Set by | Purpose |
| --- | --- | --- |
| `CLAUDE_CODE_SESSION_ID` | Claude Code | Attributes CLI calls to the Claude session |
| `CODEX_THREAD_ID`, `CODEX_SESSION_ID` | Codex | Attributes CLI calls to the Codex thread |
| `SIMFLEET_AGENT`, `SIMFLEET_SESSION_ID` | You | Identity for any other agent; takes precedence |
